AerisPulse is an enterprise-grade urban air quality and clinical mitigation platform for megacities. It integrates live Copernicus CAMS atmospheric telemetry (PM2.5, PM10, NO2, SO2, O3, CO) with automated station cross-validation, triggering safety elevation when sensor variance exceeds 25%. Under "The LLM explains; code calculates", all quantitative metrics—including ICRP inhaled particulate dosage (µg), Burnett GEMM Chronic Respiratory Exposure Index, and DEFRA modal carbon abatement—are calculated deterministically in verified TypeScript. An interactive client simulator provides real-time "What-If" lifestyle toggles with animated impact meters. A Google Gemini GenAI engine with JSON schema enforcement and Zod validation synthesizes personalized action plans, backed by an offline rules engine for zero downtime. Features SSE streaming chat with XML delimiter protection, English/Tamil/Hindi localization, 0 axe accessibility violations, and 195 automated tests.
